How to read a verdict

Gold defect — the reference answer contradicts the question it is attached to. Roughly 27 of these are executable bugs rather than matters of reading: missing parentheses that collapse a WHERE clause, a TEXT column sorted as if numeric, NULLs sorting first under ASC, a join fanning out an aggregate.

Corrected-gold check — for each gold verdict a corrected reference was written and executed, then the model's answer re-scored against it. 61 of 72 passed; 2 reversed the verdict outright and 9 turned out to be over-determined, so those moved to Both sides.

The question is authoritative. Where gold answers the question correctly and the hint's formula is broken, the failure is recorded as a model error carrying a defective-hint mark — not as a gold defect. This is stricter than the earlier convention, so 61 is a lower bound.
