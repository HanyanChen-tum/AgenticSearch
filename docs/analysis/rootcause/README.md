# 根因调查（rootcause）

本目录记录一条独立的调查线：**在剥离已知数据集问题之后，剩余的稳定失败究竟由什么导致**。

它不同于 `../analysisDetail/` 里的实验报告——那些记录"某个机制跑出了什么结果"，本目录记录"失败为什么发生"。

## 背景

`../analysisDetail/failure_decomposition_2026-08-08.md` 得出：E3-C 的 120 条失败中，77 条（64%）在六个不同配置下全部答错，机械检测器只能确证其中约 9–13 条为数据集问题。这 77 条当时被表述为"**稳定的能力缺陷**"，并据此推出"64% 的失败对整类 harness 干预免疫"。

本目录的调查检验了那个表述是否成立。

## 结论摘要（2026-08-08）

**"稳定能力缺陷"这个表述不成立。** 31 条抽样中只有约 10% 是模型真正的推理错误：

| 根因 | 题数 | 占比 |
|---|---:|---:|
| gold 本身有缺陷（已执行验证） | 10 | 32% |
| 输出约定未指定（返回 id 还是 name、含不含某列） | 9 | 29% |
| 指代歧义（两张表/两列同名） | 4 | 13% |
| Hint 与 gold 自相矛盾 | 2 | 6% |
| **模型真实推理错误** | **3** | **10%** |
| 真实语义歧义（日期粒度） | 1 | 3% |
| 待进一步判定 | 2 | 6% |

方法论要求与本项目一贯做法一致：**任何"两条 SQL 是否等价"或"gold 是否有误"的判断都必须实际执行验证**，不接受仅凭阅读 SQL 的推断。

### 全量普查确认了抽样结论（2026-08-08 补）

上表是 31 条抽样。随后对当前最优配置（e3-c + 约定后处理，82/197）的**全部 115 条失败**逐题补齐审计，
抽样比例得到确认，且 gold 缺陷与 Hint 矛盾两类的占比比抽样估计**更高**：

| 根因 | 全量 115 条 | 占比 | 抽样估计 |
|---|---:|---:|---:|
| gold 本身有缺陷 | 44 | 38.3% | 32% |
| 输出约定未指定 | 22 | 19.1% | 29% |
| 指代歧义 | 18 | 15.7% | 13% |
| Hint 与 gold 自相矛盾 | 14 | **12.2%** | 6% |
| 标注约定残留（改写规则不适用） | 7 | 6.1% | — |
| **模型真实推理错误** | **10** | **8.7%** | 10% |

详见 [`full_failure_audit_2026-08-08.md`](full_failure_audit_2026-08-08.md)，含逐题判定依据与新发现的系统性 gold 缺陷模式
（AND/OR 优先级 bug、条件恒真、经 postHistory 连接放大计数、gold 自身超时或返回 None）。

## 因果验证（2026-08-08）

审计属于观测性证据。对其中"指代歧义"一类做了**干预性**检验：只改写问题中那一个歧义名词（不出现表名/列名、不透露输出结构），其余全部不变，两臂对照。

| 指标 | 原问题 | 消歧后 |
|---|---:|---:|
| 命中预期指代对象 | 1/7 | **6/7** |
| 整题正确 | 0/7 | 2/7 |

**指代歧义被证实为真实的因果原因**——改一个名词，5 条的指代错误即被纠正，说明模型并非"选不对表"，而是题面没给出选择所需的信息。但只有 2 条整题转正，其余在指代纠正后**撞上了同一批题目并存的其它数据集侧问题**（DISTINCT 约定、输出约定、空值约定）。

这条证据把结论三从观测性提升为干预性：改变题面即改变模型行为，失败源于题面信息不足，而非模型能力。

**第二个干预性实验：Hint 消融**（`hint_ablation_2026-08-08.md`）。只删除 BIRD 的 evidence 字段，三臂对照：

| 集合 | 有 Hint | 无 Hint |
|---|---:|---:|
| A　Hint 公式与 gold 矛盾、原本失败 | 0/5 | **3/5** |
| B　同签名但原本正确 | 5/5 | 5/5 |
| C　值编码型 Hint、原本正确 | 5/5 | 5/5 |

**删除 Hint 修好 3 题、未破坏任何一题。** 机制清楚：`bird_604` 的 Hint 写 `Divide(Sum(UpVotes), Count(UserId))`，模型照做写出 `SUM/COUNT`，而 gold 用 `AVG`；删掉 Hint 后模型自行写出 `AVG`，与 gold 一致。**模型因忠实执行给定指令而被判错。**

集合 C 显示 Hint 在本样本中也非必需——推测 E3-C 的 Offline Schema artifact 已携带 `value_description`，使 Hint 内容冗余。这与 legacy 时代"Hint 为 large positive"的记录不矛盾：那是在没有 Schema Context 的 harness 上测的。
